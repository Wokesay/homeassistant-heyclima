# HeyClima (App für Home Assistant)

Die HeyClima-Oberfläche für Klimageräte von Mitsubishi Heavy Industries in der Seitenleiste von Home Assistant, per Ingress, ohne offenen Port. Anmeldung mit dem HeyClima-Konto; Steuerung über den HeyClima-Server.

Läuft in Home Assistant; kein offizielles Home-Assistant-Produkt.
