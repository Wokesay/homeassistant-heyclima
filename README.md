# HeyClima-Apps für Home Assistant

Repository für den App-Shop von Home Assistant (früher „Add-ons“). Enthält die App `heyclima`. Selbstständig und ohne Geheimnisse, damit es als eigenes öffentliches Repository gespiegelt werden kann.

Adresse in Home Assistant eintragen: Einstellungen > Apps > App-Shop > Repositories.
